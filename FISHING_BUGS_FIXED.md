# 🐟 Исправления багов рыбалки в мини-приложении

## Описание проблем

Пользователь сообщил о трех проблемах при рыбалке в мини-приложении:

1. **Звезда списывается и возвращается обратно** - при оплате за гарантированный улов звезда сначала списывалась, но потом возвращалась
2. **Не показывается сообщение при срыве/мусоре** - при бесплатной рыбалке с результатом срыв или мусор показывалось "выберите другую локацию"
3. **Кнопка не превращается в таймер** - после рыбалки кнопка не превращалась в таймер кулдауна

## Корневая причина

Backend возвращал деньги при **любой** неудаче (срыв, не клюёт, и т.д.), что было неправильно для гарантированного улова.

## Реализованные исправления

### 1. Backend: `webapp/app.py`

**Было:**
```python
# If fishing failed, refund the payment for guaranteed catch
if guaranteed and not result.get('success'):
    # Возвращаем деньги
```

**Стало:**
```python
# Деньги не возвращаются - они списаны за ГАРАНТИРОВАННЫЙ РЕЗУЛЬТАТ
# (рыба/мусор/NFT, без срывов и "не клюёт")
```

✅ Теперь деньги НЕ возвращаются при неудаче
✅ Кулдаун **всегда** синхронизируется с основным чатом после попытки

### 2. Backend: `game_logic.py`

**Было:**
```python
# In guaranteed mode, skip trash - always return fish
if adjusted_roll <= TRASH_MAX:
    adjusted_roll = TRASH_MAX + 1
```

**Стало:**
```python
# В гарантированном режиме мусор тоже может выпасть (0-7999)
if force_trash_only or adjusted_roll <= TRASH_MAX:
    # Возвращаем мусор с XP и treasure roll
```

✅ Гарантированный улов теперь включает мусор (40% шанс)
✅ За мусор дается опыт и шанс на сокровище

### 3. Frontend: `fishingScreen.ts`

**Было:**
```typescript
// Кулдаун только при успехе
if (result.success || result.is_trash || ...) {
    this.startCooldown(600);
}
```

**Стало:**
```typescript
// ВСЕГДА запускаем кулдаун после любой попытки рыбалки
this.startCooldown(600);
```

✅ Кулдаун запускается **всегда** (10 минут = 600 секунд)
✅ Текст подтверждения обновлен: "гарантированный результат"
✅ Баланс загружается с сервера после рыбалки (синхронизация)

## Логика гарантированного улова

### Что БЫЛО раньше:
- ❌ Оплата за "попытку без кулдауна"
- ❌ Мог быть срыв или "не клюёт"
- ❌ Мусор пропускался (только рыба)

### Что стало СЕЙЧАС:
- ✅ Оплата за **гарантированный результат**
- ✅ **НИКОГДА** не бывает срыва или "не клюёт"
- ✅ Может выпасть:
  - Рыба (60%, от обычной до аномалии)
  - Мусор (40%, с XP и шансом на сокровище)
  - NFT (0.005%, только при точном ролле 20000)

### Шансы в гарантированном улове:

```
0-7999   (40%)   → Мусор
8000-14999 (35%)  → Обычная рыба
15000-16999 (10%) → Редкая рыба
17000-18999 (10%) → Легендарная рыба (с нерфом x10)
19000-19499 (2.5%) → Аквариумная рыба
19500-19949 (2.25%) → Мифическая рыба
19950-19999 (0.25%) → Аномалия
20000 (0.005%)    → NFT
```

## Тестирование

Для тестирования выполните:

1. **Бесплатная рыбалка:**
   - ✅ Может быть срыв/не клюёт/мусор/рыба
   - ✅ Показывается модальное окно с результатом
   - ✅ Кулдаун запускается сразу

2. **Оплаченная рыбалка (1 звезда или 0.01 TON):**
   - ✅ ВСЕГДА есть результат (рыба/мусор/NFT)
   - ✅ НИКОГДА нет срыва или "не клюёт"
   - ✅ Деньги НЕ возвращаются при мусоре
   - ✅ Кулдаун запускается сразу
