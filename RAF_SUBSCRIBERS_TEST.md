# Тестирование системы рассылки RAF-ивентов

## Исправленные ошибки

### 1. Ошибка с chat_link
**Проблема:** `psycopg2.errors.UndefinedColumn: column cc.chat_link does not exist`

**Решение:** Исправлено использование правильного имени колонки `chat_invite_link` вместо `chat_link` в таблице `chat_configs`.

## Шаги для тестирования

### 1. Перезапустите бота
Чтобы миграция добавила новую колонку `announce_message_link` в таблицу `raf_events`:
```bash
# Остановите бота
# Запустите снова
python bot.py
```

### 2. Подпишитесь на рассылку
```
1. Откройте личку с ботом
2. Отправьте команду: /reg
3. Получите подтверждение о подписке
```

### 3. Создайте тестовый RAF-ивент
```
1. В личке с ботом: /raf
2. Введите название: "Тестовый ивент"
3. Укажите chat_id или ссылку на сообщение в чате
4. Установите длительность: 24 (часов)
5. Добавьте призы (например: "100 монет", редкость "common", шанс 50)
6. Оплатите создание ивента
7. Нажмите кнопку "Начать" когда она появится
```

### 4. Проверьте уведомление
После активации ивента:
- ✅ В целевом чате должно появиться сообщение о начале RAF-ивента
- ✅ Всем подписчикам (включая вас) должно прийти уведомление в личку
- ✅ В уведомлении должна быть кнопка "🔗 Перейти к ивенту"
- ✅ При нажатии кнопки должен открыться чат с сообщением о ивенте

### 5. Проверьте логи
В логах бота должны быть строки:
```
[INFO] RAF event {event_id} notifications sent: {count} succeeded, 0 failed out of {total} subscribers
```

## Что проверить в уведомлении

Уведомление должно содержать:
```
🎉 Новый RAF-ивент!

🏷 Название: {название ивента}
💬 Чат: {название чата}
⏱ Время: {дата начала} - {дата окончания}

🎁 Призы:
• {приз 1} ({редкость}, {шанс}%)
• {приз 2} ({редкость}, {шанс}%)
...

[Кнопка: 🔗 Перейти к ивенту]
```

## Проверка формирования ссылок

### Публичные чаты (с @username)
Ссылка должна быть вида:
```
https://t.me/{username}/{message_id}
```

### Приватные чаты (супергруппы)
Ссылка должна быть вида:
```
https://t.me/c/{chat_id_без_префикса_-100}/{message_id}
```

Например:
- Chat ID: `-1001234567890`
- Ссылка: `https://t.me/c/1234567890/123`

## Проверка отписки

```
1. Откройте личку с ботом
2. Отправьте: /reg
3. Нажмите кнопку "❌ Отписаться от рассылки"
4. Получите подтверждение об отписке
5. Создайте новый ивент - уведомление не должно прийти
```

## Возможные проблемы

### Уведомления не приходят
- Проверьте, что пользователь подписан: запрос в БД `SELECT * FROM raf_event_subscribers`
- Проверьте логи на наличие ошибок при отправке
- Убедитесь, что пользователь не заблокировал бота

### Кнопка не работает
- Проверьте формат ссылки в логах
- Убедитесь, что `announce_message_link` сохранилась в БД
- Для приватных чатов проверьте, что chat_id обработан правильно (удален префикс `-100`)

### Название чата не отображается
- Проверьте, что в таблице `chat_configs` есть запись для этого чата
- Если записи нет, бот попытается получить название через API
- В крайнем случае будет показан chat_id

## SQL запросы для отладки

```sql
-- Проверить подписчиков
SELECT * FROM raf_event_subscribers;

-- Проверить ссылки на сообщения
SELECT id, title, target_chat_id, announce_message_link 
FROM raf_events 
WHERE status = 'active';

-- Проверить информацию о чатах
SELECT chat_id, chat_title, chat_invite_link 
FROM chat_configs;
```
