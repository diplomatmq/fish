# Быстрый старт: Рассылка о RAF-ивентах

## Что добавлено

Система автоматических уведомлений о новых RAF-ивентах для подписчиков.

## Для пользователей

### Подписаться на рассылку
1. Напишите боту в личку: `/reg`
2. Получите подтверждение о подписке

### Отписаться от рассылки
1. Напишите боту в личку: `/reg`
2. Нажмите кнопку "Отписаться от рассылки"

### Что вы будете получать
При запуске каждого нового RAF-ивента вам придет сообщение с:
- Названием ивента
- Информацией о чате
- Списком призов
- Прямой ссылкой на сообщение о розыгрыше

## Для создателей ивентов

Ничего дополнительно делать не нужно! Уведомления отправляются автоматически при активации RAF-ивента (нажатие кнопки "Начать").

## Технические изменения

### Файлы
- `database.py` - добавлена таблица и методы работы с подписчиками
- `bot.py` - добавлена команда `/reg` и логика уведомлений

### База данных
Автоматически создается новая таблица `raf_event_subscribers` при запуске бота.

### Команды
- Добавлена команда: `/reg`
- Работает только в личных сообщениях с ботом

## Проверка работы

1. **Проверка подписки:**
   ```
   Боту в личку: /reg
   Ожидаемый ответ: Подтверждение подписки
   ```

2. **Проверка уведомлений:**
   - Создайте и запустите тестовый RAF-ивент
   - Все подписчики должны получить уведомление
   - В логах должна появиться информация о количестве отправленных уведомлений

3. **Проверка отписки:**
   ```
   Боту в личку: /reg (будучи подписанным)
   Нажать кнопку "Отписаться"
   Ожидаемый ответ: Подтверждение отписки
   ```

## Логирование

Все действия логируются:
- `subscribe_to_raf_events` - подписка
- `unsubscribe_from_raf_events` - отписка
- `_notify_raf_subscribers` - статистика отправки уведомлений

Пример лога:
```
[INFO] RAF event 123 notifications sent: 45 succeeded, 2 failed out of 47 subscribers
```
